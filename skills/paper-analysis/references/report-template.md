# レポートの構成

原稿（`report.md`）は、次の型で書く。見出しの名前と順序は変えない。読み手が複数のレポートを読み比べるとき、同じ場所に同じ情報があると探しやすいためである。論文の種類によって書く内容がない節は、消さずに「この論文には該当する記述がない」と一文で書く。

案内のコメント（`<!-- -->`）は原稿に残さない（HTMLにするときも無視されるが、校正の対象を減らすため）。

原文の引用（`> 原文：`）を二つ続けるときは、間に地の文を一文はさむ。どの主張の根拠かが分かるようにするためである。

````markdown
# <論文のタイトル（原題のまま）>

<タイトルの日本語訳>。<筆頭著者>ほか、<発表年>年、<発表先>

## 書誌情報

| 項目 | 内容 |
| --- | --- |
| タイトル | <原題> |
| 著者 | <全員。多いときは筆頭から5人と「ほかN人」> |
| 発表先 | <会議、論文誌、プレプリント（arXiv）など> |
| 発表年 | <年> |
| 識別子 | <arXiv ID と版、DOI。`[arXiv:2401.01234v2](https://arxiv.org/abs/2401.01234v2)` の形のリンクにする> |
| 分析に使った版 | <PDFの出所、ページ数。ページ番号の数え方（PDFの何ページ目か）> |

## 一言でいうと

<!-- 2〜3文。何を問題にし、何をして、何が分かったか。数値を一つ入れる -->

## 研究の問いと貢献

<!-- 著者が掲げる問い・目的を書き、貢献として著者が挙げている項目を箇条書きにする。著者の言葉を根拠に -->

## 背景と位置づけ

<!-- 論文が先行研究をどう整理し、自分の研究をどこに置いているか。論文が述べている範囲だけを書く。先行研究の中身を論文の外の知識で補わない -->

## 手法

<!-- 提案の中身。仕組みを、入力から出力への順に説明する。式や構成が中心なら、主要な式・構成要素を一つずつ。必要なら ### で小見出しを立てる -->

## 実験の設定

<!-- データ（名前、規模、分け方）、比較対象、評価の指標、条件。表にすると読みやすい。書かれていない項目は「記載なし」 -->

## 結果

<!-- 主な結果を、表や図の数値で示す。どの条件で、何と比べて、どれだけか。著者の解釈は「著者は〜と解釈している」と書き分ける -->

## 著者の主張と根拠の対応

| 著者の主張 | 根拠の種類 | 根拠の場所 |
| --- | --- | --- |
| <主張を一文で> | <実験／理論（証明・導出）／先行研究の引用／根拠の提示なし> | 〔p.7 表2〕 |

<!-- 根拠の種類は、論文の中で何がその主張を支えているかを分類するだけで、妥当かどうかは判断しない -->

## 著者が述べる限界と今後の課題

<!-- 論文に書かれている限界・課題だけ。書かれていなければ「論文の中で限界への言及はない」と書く -->

## 論文に書かれていないこと

<!-- 読み手が知りたくなりそうだが、論文に記載がない事項を挙げる。例：コードやデータの公開の有無、計算資源、試行回数やばらつき、特定の条件での結果。評価ではなく「記載がない」という事実として書く -->

## 論文の中の食い違い

<!-- 論文の中で、同じ事柄の記述が食い違っている箇所（本文と表で数値が違う、モデルの数が節によって違う、図と本文の説明が合わないなど）を、両方の場所つきで挙げる。どちらが正しいかは判断しない。見つからなければ「読んだ範囲で食い違いは見つからなかった」と書く -->

## 主な図表

| 図表 | 示していること | 場所 |
| --- | --- | --- |
| 図1 | <何を、どの軸で示しているか> | 〔p.3〕 |

## 用語集

| 用語 | 意味 | 場所 |
| --- | --- | --- |
| <訳語（原語）> | <論文の中での定義> | 〔p.2 §2.1〕 |

<!-- 論文の中で定義がなく、理解のために一般的な意味を添える用語は、意味の欄の先頭に「論文外の補足：」と書く -->
````

## 書き方の例

### 結果の節

```markdown
提案手法は、ImageNetの検証データで上位1位の正解率（top-1 accuracy）84.3%を達成し、比較対象のうち最も高かったResNet-152（82.1%）を2.2ポイント上回った〔p.7 表2〕。

> 原文："our model achieves 84.3% top-1 accuracy on ImageNet, outperforming ResNet-152 by 2.2 points"

著者は、この差を注意機構による長い距離の依存関係の捉え方によるものと解釈している〔p.8 §5.1〕。ただし、注意機構を外した条件の比較（アブレーション）は、表4の小規模なデータでだけ行われている〔p.9 表4〕。
```

最後の文は、論文の中の事実（比較がどのデータで行われたか）だけで構成されている。「したがって主張は弱い」のような評価は加えない。

### 論文外の補足

```markdown
> 論文外の補足：アブレーション（ablation）は、構成要素を一つずつ取り除いて、その要素の寄与を調べる実験の一般的な呼び名である。
```

本文の節では使わず、用語集の中か、用語集の直後にだけ置く。
